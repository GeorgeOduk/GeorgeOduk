### E-commerce Funnel Analysis | SQL Server + Power BI

An end-to-end funnel analysis project examining how users move through an e-commerce journey from **Home Page** to **Purchase Confirmation**.

The project uses SQL Server and Power BI to analyse conversion rates, stage-by-stage drop-offs, segment performance and time-based funnel deterioration.

**Key skills demonstrated:**

- SQL Server data cleaning and modelling  
- Funnel conversion analysis  
- Power BI dashboard design  
- Segment and time trend analysis  
- Customer journey diagnostics  
- Commercial recommendations  

**Key finding:**  
Only **0.50% of users completed the full funnel**, with major drop-offs before checkout and a sharp conversion deterioration from March 2015 onward.

[View the full project](https://github.com/GeorgeOduk/ecommerce-funnel-analysis-sql-powerbi)
